# Hotel Management System

A simple Hotel Management System built using Python and file handling.

## Features

* Add Guest
* View Guest Details
* Search Guest
* Update Guest Details
* Delete Guest Booking

## Technologies Used

* Python OOP
* File Handling
* Loops and Conditions
* Data Management

## How It Works

The system stores guest information in a text file and allows users to:

1. Add new guests
2. View all guest records
3. Search guests by Guest ID
4. Update guest details
5. Delete guest records
